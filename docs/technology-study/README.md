# Étude des technologies

Dossier pour recenser, comparer et justifier les technologies possibles.

## Structure suggérée

- `frequences-radio.md` — ISM, bandes autorisées (France), portée vs débit
- `transpondeurs.md` — passif/actif, RFID UHF, BLE, LoRa, nRF, ESP-NOW, etc.
- `detection.md` — boucle magnétique, infrarouge, laser, RFID, RSSI/TDOA, inductif
- `microcontroleurs.md` — STM32, ESP32, nRF52, ATtiny, RP2040
- `logiciel.md` — backend (FastAPI/Node), frontend (Vue/React), BDD (SQLite/Postgres), temps (NTP/PTP)
- `mecanique.md` — impression 3D, matériaux, fixation

## Méthode

Pour chaque famille : **critères**, **tableau comparatif (grille de notation)**, **justification retenue** → à reporter dans un ADR.
