# ADR — Architecture Decision Records

Un **ADR** (*Architecture Decision Record*) documente une décision technique importante :
le **contexte**, les **options envisagées**, le **choix retenu** et ses **conséquences**.

Le sujet exige explicitement de *« justifier les choix proposés »* → ces fichiers servent
directement de preuve de traçabilité.

## Numérotation

`NNN-titre-en-kebab-case.md` (ex. `001-frequence-radio.md`). Numéro incrémental, jamais réutilisé.

## Quand écrire un ADR ?

- Choix de la fréquence / du protocole radio.
- Choix de la MCU / du matériel.
- Choix de l'algorithme de synchronisation temporelle.
- Choix de l'architecture backend (BDD, API…).
- Tout arbitrage qui est difficile à revenir en arrière.
